The key is two separate scale targets and one :has() selector that prevents them from firing at the same time.

/* 1. Row press → text scales. :not(:has(.action-btn:active)) means: "only when NO button inside is being pressed." */ .row:active:not(:has(.action-btn:active)) .row-text { transform: scale(0.94); transition: transform 75ms cubic-bezier(0.4, 0, 1, 1); } /* 2. Button press → only that button's icon scales. Row text is completely untouched. */ .action-btn:active .action-btn-icon { transform: scale(0.78); transition: transform 75ms cubic-bezier(0.4, 0, 1, 1); } /* Spring-back on release (no :active = default state) */ .row-text, .action-btn-icon { transition: transform 180ms cubic-bezier(0.34, 1.56, 0.64, 1); }

The button icons scale to 0.78 (more dramatic) because they're small — a 22% reduction still looks subtle at that size. The text at 0.94 is gentler because it covers more visual area. Both use the same two-curve approach: fast in (75ms ease-in), spring out (180ms overshoot).
